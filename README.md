# Лабораторная работа №1

**Тема:** Типы данных и их внутреннее представление в памяти.

**Язык программирования:** C++

## Описание проекта

Программа предназначена для изучения внутреннего представления данных в памяти компьютера.

В программе реализованы:
- Вывод размеров основных типов данных.
- Двоичное представление целых чисел.
- Вывод битового представления float и double.
- Разделение чисел с плавающей точкой на знак, порядок и мантиссу.
- Изменение отдельных битов с помощью побитовых операций.
- Индивидуальное задание: проверка чётности числа путём обнуления младшего бита.

## Используемые технологии
- C++
- C++17
- IEEE 754
- Битовые операции
